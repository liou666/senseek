## なぜ Senseek？

Web ページは読むために書かれています。知りたい内容や条件は覚えていても、原文の正確な表現がわからないことがあります。Senseek なら、自分の言葉で説明するだけで、関連する箇所に移動できます。

汎用 LLM でも同様の検索は実現できますが、この用途には JEV がより適しています。専用の評価 API が段落の関連度判定と文の選択を高速に行うため、スムーズに検索できます。

## 仕組み

1. ツールバーのアイコンまたはキーボードショートカットで Senseek を開きます。ブラウザー標準の検索ボックスのようにコンパクトで、読み進める邪魔になりにくい設計です。
2. 「解約後も使えますか？」など、自然な言葉で質問します。
3. Senseek がページ内のテキストを短い段落に分割します。ナビゲーションリンク、ボタンのラベル、フッター、ブラウザー標準の折りたたみ要素内のテキストも対象です。
4. ブラウザーが質問と段落を JEV に直接送り、意味に基づいて関連度を判定します。
5. 結果が関連度順に並び、一致する文が元のページ上でハイライトされます。検索ボックスを展開すると、各結果とその信頼度を確認できます。

API キーはブラウザーの拡張機能用ローカルストレージにのみ保存されます。検索リクエストはブラウザーから TypeSafe/JEV に直接送信され、Senseek のサーバーを経由しません。

## Senseek と `Ctrl+F` の違い

| | `Ctrl+F` | Senseek |
| --- | --- | --- |
| 検索方法 | 単語や文字列の完全一致 | 意味、概念、言い換えによる検索 |
| 入力する内容 | 原文の表現を知っている必要がある | 探したい内容を自分の言葉で説明する |
| 検索結果 | ページ内の出現順に表示 | 意味の関連度順に表示 |
| 読み進め方 | 一致箇所を自分で確認する | 最も関連する箇所へ直接移動する |

### `Ctrl+F` の限界

- 同義語や言い換えを認識できません。
- 入力した文字列がページ内に存在する必要があります。
- 質問、条件、文脈に含まれる答えを理解できません。
- 長いページでは無関係な一致が多数見つかり、一つずつ確認する必要があります。

Senseek にも制約があります。有効な JEV API キーとインターネット接続が必要です。検索対象は現在のページ内のテキストで、ブラウザー標準の折りたたみ要素内の一致を選ぶと、その要素が自動的に開きます。画像、スキャンした PDF、アクセスできない iframe、そのほかの非表示コンテンツは検索できません。

## 使い始める

[最新のリリース](https://github.com/liou666/senseek/releases/latest)から ZIP をダウンロードして展開し、Chrome または Edge 127 以降に、展開したフォルダーをパッケージ化されていない拡張機能として読み込みます。

Settings（設定）を開き、[TypeSafe コンソール](https://console.typesafe.ai/keys)で取得した API キーを入力します。ツールバーのアイコン、または設定画面に表示されるショートカットで、Senseek を開いたり閉じたりできます。

ライセンスとクレジットについては、`extension/LICENSE` と `extension/NOTICE` を参照してください。
