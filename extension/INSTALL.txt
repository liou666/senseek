Senseek · Semantic Page Search
Find what you mean.

1. Extract the ZIP to a permanent folder. Do not try to install the ZIP directly.
2. Use Chrome or Edge 127 or newer. Open chrome://extensions or edge://extensions.
3. Enable Developer mode and select "Load unpacked".
4. Choose the folder that contains manifest.json.
5. In Settings, enter your TypeSafe API key from https://console.typesafe.ai/keys.
6. Settings save automatically. Open a regular webpage and click the Senseek icon.
   Senseek opens as a compact Ctrl+F-style search box at the top of the page.
7. Describe what you want to find and press Enter to search. Click the expand
   button to inspect ranked matches and confidence. The default shortcut is
   Alt+Shift+F on Windows/Linux and macOS; change it in the browser's extension
   shortcuts page.

Use Enter / Shift+Enter to navigate matches. Press Esc to close.
No backend, Node.js installation, or running server is required.

Searches send your query and the captured page passages directly to TypeSafe.
Your key is saved only in this browser's local extension storage.
The installation package does not contain an API key.
Vercel AI Gateway keys cannot be used with this extension.
Browser settings, extension stores, built-in PDF viewers, and iframe content
are not supported.
Restricted pages show a small notice below the toolbar icon without opening a tab.
